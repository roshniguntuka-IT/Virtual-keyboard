# Virtual Keyboard

A responsive, browser-based virtual keyboard built using HTML, CSS, and JavaScript. It allows users to enter and edit text using an on-screen keyboard or their physical keyboard.

# Features

- **Virtual Keyboard:** Type letters, numbers, symbols, and special characters.
- **Shift & Caps Lock:** Support uppercase letters and shifted symbols.
- **Text Editing:** Use Backspace, Delete, Enter, Tab, and Space.
- **Cursor Navigation:** Move through text using arrow keys, Home, and End.
- **Copy Text:** Copy entered text to the clipboard.
- **Clear Text:** Clear the text area with a single click.
- **Responsive Design:** Adapt the interface to different screen sizes.
- **Accessibility Considerations:** Semantic HTML, visible focus indicators, and live status announcements.
- **Physical Keyboard Support:** Enter text naturally using a physical keyboard.

# Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Event Handling
- Clipboard API
- ARIA Live Regions

## Getting Started

### 1. Clone the repository
git clone https://github.com/roshniguntuka-IT/Virtual-keyboard.git

### 2. Open the project folder
cd Virtual-keyboard

### 3. Run the application

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No additional dependencies are required.

## How to Use

1. Open the application in your browser.
2. Click inside the text area or select a virtual keyboard key.
3. Type and edit text using the available keys.
4. Use Shift and Caps Lock to change letter case.
5. Click **Copy Text** to copy your input.
6. Click **Clear Text** to remove the entered text.

## Accessibility Considerations

This project incorporates several accessibility-minded practices:

- Semantic HTML elements and descriptive controls.
- Visible focus indicators for interactive elements.
- An ARIA live region for status updates.
- Native text-area editing and physical keyboard input.
- Responsive layout considerations.
- A reduced-motion preference in CSS.

The virtual Control, Alt, and Meta keys provide visual feedback only and do not simulate operating-system shortcuts.
